# MNIST Deep Learning Practice

MNIST 손글씨 숫자 데이터셋을 이용하여 딥러닝의 기본적인 학습 과정을 실습한 프로젝트입니다.

## 학습 내용

### DAY 01
- MNIST 데이터셋 확인
- 완전연결 신경망 구현
- Cross Entropy Loss
- SGD / Adam Optimizer
- 모델 학습 및 테스트
- 정확도 확인

### DAY 02
- CNN의 기본 구조 이해
- Conv2d
- ReLU
- Max Pooling
- Feature Map 확인
- CNN 모델 구현
- Batch 단위 학습
- Epoch 학습
- 테스트 정확도 측정
- 오분류 이미지 확인

## 사용 환경

- Python
- PyTorch
- torchvision
- matplotlib
- Google Colab
